T Green Naturals - Mobile App Starter

This is a mobile-first installable web app (PWA) for T Green Naturals.
Features:
- Home screen
- Product catalog
- Add to cart
- Cart quantity controls
- WhatsApp order flow
- Uses the existing T Green Naturals WhatsApp number from the website

To use:
1. Upload these files to the same GitHub Pages repository as the website (or a new repository).
2. Open the published HTTPS link on an iPhone/Android phone.
3. Use Add to Home Screen / Install App.

Next upgrades can add real online payments, customer login, order history, delivery charges, admin order management, and product images.
